  • 2026년 9월 10일에 확인한 가격을 정리한 페이지입니다. 실시간 가격 조회 기능은 없으며, 구매 전 연결된 상품 페이지에서 현재 가격을 확인하세요.

  • 14인치 Pro 64GB는 18코어 CPU / 20코어 GPU가 필요합니다. Max 48·64GB는 18코어 CPU / 40코어 GPU 구성입니다.
